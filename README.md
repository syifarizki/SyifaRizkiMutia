
# Syifa Rizki Mutia — Personal Portfolio

A personal portfolio website showcasing my experience, skills, and projects as a Web Developer. Built with a focus on clean design, responsive layouts, and smooth animations.

## Features

- **Hero Section** — Personal introduction.
- **About Section** — An overview of my background and interests in web development.
- **Experience Section** — Professional experience and internship history.
- **Skills Section** — Technologies and tools I use for web development.
- **Projects Section** — A collection of selected websites and web applications.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Social Links** — Quick access to my professional profiles.

## Tech Stack

- React JS
- Vite
- Tailwind CSS
- JavaScript
- Motion
- React Icons

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your computer.

### Installation

1. Clone this repository.

   ```bash
   git clone https://github.com/syifarizki/SyifaRizkiMutia
   ```

2. Navigate to the project directory.

   ```bash
   cd syifa-portofolio
   ```

3. Install dependencies.

   ```bash
   npm install
   ```

4. Start the development server.

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
